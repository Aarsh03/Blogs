## 2. File-by-File Audit & Required Changes

### File 1: `product.md`
**Status:** ⚠️ **Needs Significant Updates**

#### Discrepancies & Outdated Information:
1. **Section 3.1 (Folder Structure):**
   - **Outdated Pages:** Lists `/pages/search.astro`, `/pages/tags/index.astro`, and `/pages/tags/[tag].astro`. In reality, these routes do not exist. Search is handled client-side via `Search.astro` directly on `index.astro`, and tag filtering is interactive on the homepage (`/?tag=...`).
   - **Missing Pages / Endpoints:** Missing `src/pages/open-graph/[...route].ts` (dynamic OG image generation) and `src/pages/rss.xml.ts` (RSS feed).
   - **Missing Config Files:** Missing `src/config.ts` and `src/content.config.ts`.
   - **Missing Components:** Does not list `RelatedPosts.astro`, `SeriesBox.astro`, `ScrollToTop.astro`, and `ViewCounter.astro`.
   - **Missing Public Assets:** Does not list `public/giscus-dark.css` or `public/og-image.png`.

2. **Section 3.2 (Frontmatter Schema):**
   - Missing the optional `series: "Series Name"` property (supported in `src/content.config.ts` and implemented via `SeriesBox.astro`).
   - Lists `slug: "my-post-title"` as an optional frontmatter property. Under Astro v5/v7 Content Layer (`glob()` loader), post slugs are derived directly from the filename / entry `id` (`[...slug].astro`), and `slug` is not a frontmatter field in `src/content.config.ts`.

3. **Section 4 (Pages & Navigation):**
   - **Navbar description:** States `Home · Tags · Search · About`. In reality, the navbar contains only `Home` and `About` (Search and Tags are integrated into `index.astro`).
   - **Missing Navbar Feature:** Does not document the auto-hiding navbar behavior (hides on downward scroll, reveals on upward scroll).
   - **Section 4.1 (Home):** Does not document the interactive tag filtering pills, the client-side Pagefind search bar, or the infinite scroll / pagination (`IntersectionObserver` loading 10 initial posts + 6 posts per scroll).
   - **Section 4.2 (Individual Post):** Missing documentation for:
     - Page View Counter (`ViewCounter.astro`)
     - Multi-part series navigation (`SeriesBox.astro`)
     - Algorithmic Related Posts recommendations (`RelatedPosts.astro`)
     - Jump-to-comments button (`.comment-btn` navigating to `#comments`)
     - Code block copy buttons (`copy-code-btn`)
     - Image zoom (`medium-zoom`)
     - Dynamic OG images (`/open-graph/[slug].png`)
   - **Sections 4.3 & 4.4 (Tags & Search):** Describe standalone `/tags` and `/search` pages that do not exist.

4. **Section 5 (Design System):**
   - Does not describe the dark mode tag color variations (`[data-theme="dark"] .tag:nth-child(4n+x)`), frosted glass UI styling, scroll-to-top FAB styling, or reading progress bar gradients.

5. **Section 6 (Infrastructure):**
   - **Section 6.1 (Comments):** Mentions only `giscus-theme.css`. Should document that `giscus-dark.css` is dynamically swapped when switching to dark mode via MutationObserver.
   - **Section 6.2 (Likes & Views):** Only documents `/likes/:slug`. The Cloudflare worker also implements `GET /views/:slug` and `POST /views/:slug` with `sessionStorage` tracking.

6. **Section 8 (Feature Checklist):**
   - Missing checklist entries for:
     - Auto-hiding navbar on scroll
     - Code block copy button
     - Jump to comments button
     - Dual Giscus light/dark theme switching
